# 2-minute demo script

1. **Problem (15s).** "Three years of ghat water tests sit in 90–120 page PDFs. Nobody compares them to legal limits. Durga visarjan is on 20 October."
2. **User (10s).** "Our user is one BMC officer deciding where to send cleaning, aeration and testing."
3. **Ranked list (25s).** Open the app, pick *Durga*. "Seven ghats, ranked. Bairagarh is highest risk, and it is marked low data confidence: the report has no Durga 2025 table, so we show that gap instead of calling it clean."
4. **Traceable reason (30s).** Select Bairagarh. "Dissolved oxygen read 0 mg/l twice in the Durga tests." Show the chart against the red CPCB limit, then the raw rows with report page numbers. "Every number links to the PDF page."
5. **Hindi + English brief (25s).** Switch to हिन्दी, click the brief download, open it. "One page the officer can print, with actions: clean, aerate, take a fresh sample."
6. **Honesty (15s).** Open the limitations panel. "Units are assumed, no coliform data, missing readings are never counted as clean, and this is a ranking aid, not a health certificate."
